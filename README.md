# 🍔 Stellar Burgers

**Stellar Burgers** — одностраничное приложение (SPA) для создания и оформления бургеров.

Пользователь может зарегистрироваться, авторизоваться, собрать бургер из доступных ингредиентов, оформить заказ, просматривать историю своих заказов и управлять личным профилем.

---

## 🚀 Основные возможности

- 🔐 Регистрация и авторизация пользователей
- 👤 Личный кабинет
- 🍔 Конструктор бургеров с Drag & Drop
- 📦 Оформление заказа
- 📜 Просмотр истории заказов
- 🔄 Получение данных с REST API
- 🛡️ Защищённые маршруты
- ⚡ Глобальное управление состоянием через Redux Toolkit
- 📖 Документация компонентов в Storybook

## 📂 Структура проекта

```
src
├── app          # Инициализация приложения
├── pages        # Страницы приложения
├── widgets      # Крупные UI-блоки
├── features     # Пользовательские сценарии
├── entities     # Бизнес-сущности
├── shared       # Общие компоненты, хуки, утилиты
└── services      # Работа с API и глобальным состоянием
```

Проект организован по принципам Feature-Sliced Design, что позволяет разделять ответственность между слоями приложения и упрощает масштабирование проекта.

## ⚙️ Запуск проекта

Установить зависимости

```bash
npm install
```

Запустить приложение

```bash
npm start
```

или

```bash
npm run dev
```

(в зависимости от используемой конфигурации)
